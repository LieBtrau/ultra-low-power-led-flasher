# Ultra low power LED

The original project has been designed in [2020](./2020/).  See more about this project on [Hackaday.io](https://hackaday.io/project/169882-ultra-low-power-led).

In [2026](./2026/DN_ulp-flasher.md), the idea has been reused to create a "glow-in-the-dark" like effect for a night light.  The RTC has been replaced by a [low power oscillator](http://www.discovercircuits.com/H-Corner/Ultra%20low%20current%20oscillator.htm), also used by Stephan's [Yet another ultra low power LED](https://hackaday.io/project/203844-yet-another-ultra-low-power-led).
